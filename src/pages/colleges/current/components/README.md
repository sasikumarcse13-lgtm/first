# Component structure

Each reusable component has its own folder so it is easy to locate and edit.

- `Navbar/Navbar.jsx` — top navigation and mega menus
- `Footer/Footer.jsx` — site footer
- `Layout/Layout.jsx` — shared page shell
- `SEO/SEO.jsx` — page metadata
- `CollegeIcon/CollegeIcon.jsx` — icon system
- `Loading/Loading.jsx` — loading state
- `Admission/AdmissionLeadModal.jsx` — college admission form
- `Counselling/CounsellingModal.jsx` — free counselling form
- `Breadcrumbs/Breadcrumbs.jsx` — breadcrumbs
- `TitleCards/CollegeCard.jsx` — reusable college-card location for future card extraction

Global styling is in `src/index.css`.
