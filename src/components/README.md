# Global Components

Only site-wide reusable components belong here: Navbar, Footer, and Ad.
Page-specific UI belongs inside each page's `Components/` folder.

Global component rule:
- Navbar and Footer are global.
- Advertisement/SponsoredBanner.jsx is the global sponsored banner shown on pages that need it.
- Advertisement/AdRail.jsx is the global image-ad rail for sidebar/placement use.
- Home/Components contains Home-only sections; advertisements do not belong there.
